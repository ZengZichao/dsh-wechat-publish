# 交付后自查（用户常问"有没有错误和遗漏"，务必主动跑）

人眼通读无法可靠覆盖这些检查。实测（2026-10-03，`s41522-026-01148-8`）：
**七项自动化审计 + 一次人工译义复核查出 7 处真问题**（学名误写 1、引号形态 5、译义/断句 4）。

本文件自包含，可独立执行。若同一任务已装 `文献翻译质量核查` 技能，它负责完整核对流程与报告口径，
判据与本文件一致（以本文件为准）。

## 终态判定（只读，绝不覆盖交付文件）

```bash
python3 <技能目录>/scripts/postprocess.py "<基名>_中文翻译.md" --check-only
```

两种合格结果：
- 报「无需自动修复」→ 已达规范终态；
- 报「仍可自动修复 N 行」→ 逐条核对差异**是否恰好是你在复核清单处有意回退的那几项**
  （回退过的 PMID / 编号会被再次命中，属预期）；出现回退项之外的差异才算不合格。

不要用非只读模式做终态判定：脚本默认原地覆盖，会把人工回退过的标识符再次改写。

## 七项自动化审计

1. **拉丁学名集合差集（CN vs EN 双向，最有效）**
   `names(CN) - names(EN)` 即误写，`names(EN) - names(CN)` 即漏译。
  （实测靠它抓出 `Sigarchaeales`（应为 `Signarchaeales`）——10 余处学名里人眼必漏。）
   正则：`\b[A-Z][A-Za-z]*(?:archae[a-z]*|bacterota|mycocota|plasmatota)\b` ∪
   `\b[A-Z][a-z]+(?:aceae|aeales|aeia|aeota|aeon|ales|ia)\b`。
   差集里须排除已本地化的词（`Australia`→澳大利亚、`Wikimedia` 只在图注）。

2. **引号字符直方图**：分别统计 ASCII `"`、`“”`、`‘’`、`「」`。
   中文标点须全角（ASCII 直双引号是漏网项），且**简体中文不用 `「」`**（须换 `“”`）；
   英文原文的弯引号在中文侧要转成全角。
   `postprocess.py` 的括号收口**只管括号不管引号**，引号得自查。

3. **逐节数字多重集比对 + 逐条溯源**：`Counter(数字)` 逐节相减，**每个差值都要打印上下文人工判定**，不可只看数量。

4. **关键事实点中英双向命中**：把 pH、温度、深度、计数、基因名、补充材料编号列成 30–50 项
   `(英文正则, 中文正则)` 逐条验。
   正则里破折号要写字符类 `[–-]` 而非 `.`（`2–4 cm` 用 `.` 匹配不到）；统计值要避开 `$ ^{***} $` 之类包裹。

5. **图版指代与图注双向核对**：`postprocess.py` 已内置 `check_figure_placeholders`
   （每条前置 `**图N**` 图注须在正文有 `[图N]`／见图N 指代，指代不存在的图也告警）。
   段落配对审计**查不出**漏写指代——占位在配对时被过滤掉，所以这项必须独立跑。
   表**不需要**中文侧 `[表N]` 占位（SKILL 五.5：Markdown 表就地呈现即为原位指代）；
   Springer 类源在英文侧发 `[Table N]` 占位时，要核对的是"英文占位数 = 题注数"，不是给中文补占位。

6. **表格行数单独核对**：英文 `<tr>` 数 vs 中文 `|` 行数。
   实测靠这一步查出中文漏译整张 Table 1（8 行），而按节段落配对因表格被过滤完全看不出来。

7. **括号配平**：逐行 `count("(") - count(")")`，非 0 即报（`postprocess.py` 的"括号形态"网关会在不匹配时报出，
   多属不配平而非形态问题）。

## 逐节配对的口径

**按节 + 按类型过滤后配对**，否则全是假警报。须过滤三类：
- 图版占位符——英文侧是多行块 `[Figure 1]\n\nA. …`、中文侧是单行 `[图1]`；
- `<table …>` 只在英文侧、Markdown 表格行 `|` 与 `**小标题**` 只在中文侧；
- 文末 `作者： ` 行中文侧天然多一条。

过滤齐全后应达到"逐节段数完全对应"。

## 固有假阳性（勿据此回改）

- **用错文件会一次假报多项**：做**事实核对**用 `_英文识别.md`（图注在其 CAPTIONS 块内），
  做**逐节配对**用 `_英文排版.md`（正文纯净）。中文侧多出的数字通常来自前置图注（落在 `## 摘要` 节内）。
- `Ga → 亿年` 换算必然产生数字差集（`~2.4 Ga`→`24 亿年前`），属正确换算。
- 地名/机构名本地化造成的词集差异。
- 图/表编号格式差异。
- 脚手架块（`PDF METADATA` 里的 DOI）数字已不参与 `--source` 漂移比对，若仍见 DOI 分段差值，说明传错了源文件。

## 四类必须人工过、脚本抓不到的译义问题

1. **地理方位断句错位**：`lie at the north end…, immediately to the south of X` 译成"紧邻 X 以南"自相矛盾
   （紧邻即相邻，再加方位词逻辑冲突），须改"处在 X 以南"；插入的破折号还易让同位语"那是一个…盆地"悬空。
2. **逐字直译生硬词**：`sulfur-respiring` ≠ "呼吸硫的"，应"硫**呼吸型**的"；`favored` ≠ "最被认可"，应"首选"。
3. **译名连读歧义**：`mesocosm` 译"中宇宙"后若紧接"中"（"在实验室中宇宙中维持"）极易读成"宇宙中"，
   须改写为"经实验室中宇宙（mesocosm）培养…"。
4. **同义反复的冗赘修饰**："这两个由咸水至超咸水的湖泊"三重定语，须压成"咸水至超咸水的…湖"。

## 原文自身不一致的处理

同一篇里引言作 `45 phyla`、Data Overview 作 `47 phyla`（摘要作 `>15,600` 而正文作 `15,625`）——
**属原文内部不一致，一律忠实现状、不得"统一"**，在交付说明中向用户标注即可。
图注 `(b–b)` 系 `(b–h)` 之误、credit 行与前文重复冲突这类，可据内证保守改正并在交付说明中注明依据。
