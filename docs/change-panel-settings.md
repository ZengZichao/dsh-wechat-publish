# 修改面板设置

面板只允许改三个值；其余项都按环境变量、固定值或自动探测的结果**只读展示**，让你知道当前到底在用哪一套配置。开始前确认你知道改的是「面板发起的那次任务」，不是全局环境。

1. 打开侧栏 **公众号发布**，切到 **设置**。

2. 看四个分组：**渲染**、**翻译**、**凭据**、**环境**。

3. 找带 **环境变量已覆盖** 标注的项。

   > 提示：带这个标注说明同名环境变量已经设了，面板里改也不会生效。要改就改环境变量并重启 DSH。

4. 改 **正文体积上限（字节）**。

   > 提示：填 `0` 表示用默认的 512 KB。这个值只在面板发布时作为 `WECHAT_MAX_CONTENT_BYTES` 传给发布任务。

5. 改 **Python 解释器**。

   > 提示：留空表示自动选择。要固定就填解释器的绝对路径，例如插件 `.venv/bin/python`。

6. 改 **主题缓存（小时）**，控制主题 CSS 在本地缓存多久。

7. 点 **保存**。

8. 看到 **已保存**。

**结果：** 三个值写入 `$DSH_HOME/dsh-wechat-publish/settings.json`。下一次在面板里发布时，发布任务按新的体积上限执行；**Python 解释器** 的改动同时作用于面板的预览与发布。

> **配图**：设置页。（替代文本：设置页四个分组，渲染组里三个输入框可编辑，右下角是「保存」按钮。）

> 提示：**凭据** 组永远只读，面板不保存 AppSecret。设了环境变量时，这一组会标 **环境变量已覆盖**；没设时值显示 **未设置**，并标 **缺失**。主题、公式渲染这类项在服务端标记为固定，面板不提供修改（例如主题固定为「数据研报」）。

> 提示：命令行 `publish.sh` 不读 `settings.json`，它只看环境变量。要让命令行也改体积上限，用 `WECHAT_MAX_CONTENT_BYTES=2097152 ./scripts/publish.sh ...`。
