# 浏览并打开 Markdown 文件

文件树只在 **预览** 页出现，用来找文章、切换目录、新建草稿文件。开始前需要在 DSH 侧栏打开 **公众号发布**。

1. 打开 **公众号发布**，切到 **预览**。

2. 点 **文件**，显示文件树。

   > 提示：只有在 **预览** 页才有 **文件** 开关；切到 **草稿箱** 或 **设置** 时文件树自动隐藏。

3. 点目录名进入下一层。

4. 点 **上一级** 回到父目录。

5. 点 **刷新** 重读当前目录。目录每 30 秒也会自动刷新，外部新建或改名的文件会自己出现。

6. 在 **筛选当前目录** 输入关键词，过滤当前目录里的名字；点 **只看 .md** 只显示 Markdown。

7. 点文件名打开它，路径会自动填进 **Markdown 文件路径**。

8. 点 **新建 Markdown**，在当前目录生成一个 `未命名.md`。

   > 提示：重名时服务端自动改用 `未命名 2.md`、`未命名 3.md`，不会让你先输文件名。新文件已带 `title: 未命名文章` 的 frontmatter 与一级标题。

9. 在底部的 **最近打开** 里点任意一条，重新打开最近编辑过的文章。

> **配图**：展开的文件树。（替代文本：左侧文件树，顶部是「上一级 / 刷新 / 只看 .md」按钮，中间是目录与文件列表，底部是「最近打开」。）

> 提示：首次打开面板时，文件树先落到上次浏览的目录（记在浏览器 localStorage）；没有记录时依次退到当前文章所在目录、用户主目录。目录超过 2000 项时只显示前 2000 项。

**结果：** 选中的文件出现在预览页，**Markdown 文件路径** 里是它的绝对路径，标题与统计行随之更新。
