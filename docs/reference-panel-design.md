# 查阅面板设计约定

参考页，面向要改界面的人。面板的视觉规则不是偏好，是约束：改动时按这里的口径走，别引入新的色值、字号或阴影。

## 配色

全部取自 Radix UI Colors 的灰阶加蓝（强调）、绿/红/琥珀（语义），按 Radix 的 12 阶用法分级：

| 阶 | 用途 |
|---|---|
| 1 | 页面底 |
| 2 | 次级底 |
| 3 | 选中底 |
| 4 | 悬停底 |
| 6 | 细线 |
| 7 | 控件描边 |
| 8 | 悬停描边 |
| 9 | 实心 |
| 10 | 实心悬停 |
| 11 | 次级文字 |
| 12 | 正文文字 |

亮色与暗色两套令牌由面板启动时探测宿主主题切换，跟随宿主，不跟随操作系统。

## 字号与层级

- 只有 12 / 13 / 15 三档，最小 12 px。
- 层级靠字重（400 / 500 / 600）、颜色深浅与间距表达，不靠字号跳级。

## 边框、圆角、动效

- 边框一律 0.5 px；无阴影，无卡片左色条。
- 容器与预览纸面圆角为 0；只有输入框与按钮用 4 px；嵌套处保持同心。
- 没有过渡与关键帧，状态变化即时呈现；焦点态用 2 px 外描边。

## 文案

- 不使用中点分隔符，不堆叠解释性文字。
- 需要用户判断的操作（重复发布、开启学术译文模式删表）放在用户本来就要做选择的位置，不另起说明页。
