# 修改文章标题、摘要、封面与学术译文模式

在面板里改文章开头的字段，不用打开编辑器。你要先打开一篇文章，并知道两种生效范围的区别：**预览效果** 只改这一次预览，**保存到文件** 才写回磁盘。

1. 按 [浏览并打开 Markdown 文件](open-and-browse-files.md) 打开一篇文章。

2. 在标题下方展开 **文章信息**。

3. 修改需要改的字段：**标题**、**作者**、**摘要**、**封面图路径**。

   > 提示：改了还没保存时，**文章信息** 折叠标题的右侧会显示 **未保存**。

4. 点 **预览效果**。预览按新字段重渲染，源文件不动；关掉面板或重新打开这篇文章就恢复。

5. 确认效果后点 **保存到文件**。

6. 看到 **已保存**，并在文章同目录找到一份 `article.md.wxpanel.bak` 备份。

7. 需要学术译文模式时，打开 **学术译文模式**，在确认框里点确认。

   > 提示：确认框写的是「开启后会移除正文全部表格，只留表题。继续？」。表格里有实质数据时不要开，内容会静默消失。

**结果：** 预览与后续发布的草稿都用新字段；源文件的 frontmatter 已更新，正文未被改动；同目录留有 `.wxpanel.bak` 备份。

> **配图**：展开的「文章信息」卡片。（替代文本：卡片内依次是标题、作者、摘要、封面图路径四个输入框，「学术译文模式」开关，以及「预览效果」「保存到文件」两个按钮。）

## 几条兜底规则

- **标题留空**：面板按「第一个标题 → 第一段文字 → 文件名」的顺序补；命令行发布不会补，必须写 `title`。
- **封面留空**：面板发布时自动生成 940×400 白底、带标题文字的兜底封面；命令行发布必须有 `cover`。
- **作者上限 8 字节**：三个汉字是 9 字节，装不下。建议留空，让公众号前台显示账号名；要署名就写不超过 8 字节的短名。
- **摘要上限 120 字节**：中文约 39 字。留空时发布用标题当摘要。

字段的完整含义与上限见 [查阅 frontmatter 字段](reference-frontmatter.md)。
