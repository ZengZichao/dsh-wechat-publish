# 发布前预览文章排版

在不写草稿箱、不调发布接口的前提下，先看文章排成公众号样式后的样子。需要插件已启用，并有一篇本地 Markdown。面板预览与真实草稿用的是同一套主题 CSS 与公式 SVG，所以看到的效果就是草稿箱里的效果。

## 在面板里预览

1. 打开侧栏 **公众号发布**，停在 **预览** 标签。

2. 在 **Markdown 文件路径** 粘贴绝对路径，按回车或点 **打开**。

3. 看标题下方的统计行：字节数、图片数（缺失数）、`SVG` 数、表格数。

4. 看统计行上方的告警列表。缺图、远程图片、超过 1MB、会触发裁剪，都只在这里提示。

5. 需要改标题、摘要、封面时，展开 **文章信息** 修改；点 **预览效果** 只影响本次预览，源文件不动。

6. 改完点统计行末尾的 **刷新**，重新渲染。

**结果：** 纸面显示与草稿箱一致的正文：主题样式已内联、公式是 SVG、表格是三线表、图片正常显示。

## 在命令行预览

把 `<插件根目录>` 理解为 `dsh-wechat-publish/` 的绝对路径。

```bash
cd <插件根目录>/skills/wechat-publish
./scripts/publish.sh "/绝对路径/article.md" --no-publish --out preview.html
```

把 `preview.html` 用浏览器打开即可。

> 提示：`--no-publish` 需要联网抓主题 CSS；抓不到时样式会不完整。

> 提示：`--no-publish` **不读任何图片文件**。图片是否存在、是不是假图、有没有超过 1MB，都只在真发布路径里检查。预览通过不等于能发布，图片要另按 [排查图片与封面问题](troubleshoot-images-and-cover.md) 审一遍。

> 提示：`--no-publish` 可以省掉 frontmatter 的 `cover`；真发布不能省（面板会自动生成兜底封面，命令行不会）。
