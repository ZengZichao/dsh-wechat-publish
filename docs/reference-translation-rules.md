# 查阅译文格式规则

参考页：译文长什么样，由下面这些约定决定。任务步骤见 [把英文 PDF 译成中文 Markdown](translate-an-english-pdf.md)。

## 保留与省略

- **保留并翻译**：摘要、正文、图注、标题。
- **整节省略**：材料与方法、致谢、关键词、利益冲突、数据可用性、作者贡献、基金资助、参考文献、附录与补充材料，以及补充材料说明、伦理声明、版权行等后端小节。
- 脚本会把这些整节剔除，并留 `<!-- SKIPPED: ... -->` 供核对；若摘要位置出现该注释，说明误删了，要回填。
- 作者署名段从标题下方移除，统一放到全文末尾：`作者： Smith J, Zhang L`。

## 结构

- 首行是加粗的 `**期刊名｜文献标题**`：不加 `#`，`｜` 用全角竖线 U+FF5C 且前后无空格，不要用半角 `|`。
- 期刊名默认用英文原名（如 `Nature Reviews Microbiology`），用户明确要求中文刊名时才用白名单里的中文名并加书名号。
- 正文标题从 `##` 起，按原文层级用 `###`、`####`。首个正文标题必须是 `##`，不能跳级。
- 原文的 `Introduction` / `Intro` / `Background` / `Main` 统一译成 `## 引言`；原文连一段无标题的引言都没有时，补 `## 引言` 作父级、把首个具名小节降为 `###`。
- 图表标题集中在「摘要之后、正文之前」，前面不加「图表目录」这类总标题。图 `**图1**：标题`，表 `**表1**：标题`，序号沿用原文，冒号用全角。
- 正文讨论图的地方，独立成行写 `[图N]`；不用「见图N」这种散文写法。

## 标点与数字

- 段间空一行，不用段首缩进，全文 Markdown。
- 括号看内容定形态：括号内有汉字或中文标点用全角 `（）`，纯西文、数字、URL 用半角 `()`。弯引号和全角拉丁字母不算汉字。
- 中文标点全角，引号用弯引号 `“”` `‘’`，不用 ASCII 直双引号，简体也不用 `「」`。
- 数字与单位之间加半角空格：`5 mg`、`37 °C`、`1.2 mL`。
- ≥1000 的独立整数加千分位（`1,000`）；年份、区间两端、命令行参数、保藏号、紧邻汉字的编号、后接「万年」这类数量级词不加。
- 时间量词统一用「百万年 / 万年 / 亿年」制式。
- 数字 + M 不自动改：`1M reads` 是百万，`5 M HCl` 是摩尔，脚本只告警，需要人判断。

## 公式

- 行内 `$...$`，独立公式 `$$...$$` 独占一段。化学式一律 LaTeX：`$\mathrm{H_2O}$`、`$\mathrm{CO_2}$`。
- 无法可靠还原时（LaTeX 含乱码、`$` 或 `\` 未闭合、上下标粘连、只剩零散符号），保留原文符号并加 `【原文符号】`，不要臆造。
- 上下标粘连只有能回源确认时才允许重构（如 `$10^{32}$`、`65–75%`）；确认不了就按上一条降级。

## 引用

- 最终译文不保留任何引用标注：`[1]`、`(Smith, 2020)`、上标数字、文末引用列表。
- 引用剥离由脚本确定性完成，覆盖方括号编号、作者年、逗号或分号多引用组、19 世纪年份、非 ASCII 姓氏、行号噪声。
- 叙述型引用（`Gould (1966) defines`）脚本有意不吞，否则句子会断。译文化入行文：「Gould 于 1966 年将……定义为」，不要留括号，也不要回填编号。

## 常见误伤与自查

- 后处理会给表格里的长数字列（如 PMID）误加千分位，要回源表批量替换回去。
- 交付前跑 `postprocess.py --check-only`；报「无需自动修复」才算收口。
- 用户问「有没有错漏」时，按 `skills/paper-translation/references/self-audit.md` 的七项审计逐条查。
